## H1 支持 · 按题抽样得到更宽的区间

每个切片、每种算法都用 Mulberry32 重新初始化种子 `20261121`，抽取 10,000 个 bootstrap 样本。按 qid 升序排列数据，展开数组在每题内按轮次升序。每次抽取与原样本等量的单位，用 `floor(U × n)` 选下标并放回。按 trial 用每行的 0/1，按题用每题三轮正确率，随后求均值。两种算法的点估计相同，因为每题均有三轮。

均值升序排列后，分别取 2.5% 和 97.5% 分位。对分位 `p` 使用零基下标 `(10000 − 1) × p`，按小数部分在相邻值间线性插值。上界减下界得到宽度，最后统一显示四位小数。

## H3 不确定 · 规则标记需要语义复核

只检查 `pipeline=agentic` 且 `correct=true` 的 116 行。共命中 86 行。

| 规则 | 定义 | 命中行数 |
| --- | --- | ---: |
| 非金标 SKU | 匹配大写 `DH-[A-Z]{2}-\d{4}`，两侧排除 ASCII 字母、数字及连字符。去重后若有任一 SKU 不在 `gold` 即标记 | 86 |
| 空白 | `rationale` 为 null 或去掉首尾空白后为空 | 0 |
| 明确否认匹配 | `answer` 非空，且解释匹配 `(?:没有\|无\|未找到)(?:任何)?符合(?:全部)?条件的商品` | 0 |

- **m01，第 1 轮**。解释写「DH-TC-0915 本身（180ml，不满足“更大”）」。`DH-TC-0915` 是用于比较的基准，规则仍将它标记为非金标 SKU。
- **n01，第 2 轮**。解释写「全文检索“天青釉/汝窑/青釉”也只返回了猪油白釉的 DH-TC-0915、象牙白釉的 DH-TC-1026 和中国白釉的 DH-BP-1049，均不是天青釉或汝窑产品」。金标为空，列出被排除的检索结果也会触发规则。

精确匹配只检查答案集合。非金标 SKU 规则会标记合理的对照或排除说明，矛盾规则仅覆盖特定措辞。规则命中无法给出解释错误率，本集上的解释正确性仍不确定。**LLM judge SKIPPED**，本轮统计完全离线，未读取密钥、未调用模型。

## H4 支持 · 符号检验以题目为独立样本单位

按题时，比较同一 qid 下 agentic 与 fixed 的三轮准确率，直接用正确次数之差取符号。展开时，按 qid 和 run 配对，比较每对 0/1。表中胜、负、平以 agentic 为基准，`n` 包含平局。

精确双侧检验排除平局。记胜负总数为 `m`，胜负数较小者为 `b`，在零假设下计算 `p = min(1, 2 × P[Binomial(m, 0.5) ≤ b])`。实现从 `2^(-m)` 起逐项乘 `(m − k + 1) / k` 累加至 `b`。全平时 `p = 1`。

| 切片 | 按题 n | 胜/负/平 | p | 按 trial n | 胜/负/平 | p |
| --- | ---: | --- | ---: | ---: | --- | ---: |
| single | 13 | 1/0/12 | 1.0000 | 39 | 2/0/37 | 0.5000 |
| multi | 14 | 9/0/5 | 0.0039 | 42 | 25/0/17 | 5.960464e-8 |
| null | 13 | 1/2/10 | 1.0000 | 39 | 1/4/34 | 0.3750 |
| all | 40 | 11/2/27 | 0.0225 | 120 | 28/4/88 | 1.930119e-5 |

展开结果复核 2.3 的口径，多跳和全部的精确 p 值均小于 0.001，冻结 JSON 将它们显示为 0。四个切片展开后的 p 值都更小。重复 trial 对来自同一题，推断时应按题配对。若预先声明了 trial 指标，推断仍应保留同题聚类，不能把三轮当作三道独立题。

## 复现

在包含上述 Git 提交和 2.3 源文件的 worktree 中，进入本 demo 目录。环境为 Node.js 24 或以上和 pnpm 10.34.6。验证使用 Node.js 24.22.1。

```bash
pnpm install --frozen-lockfile
pnpm analyze
pnpm test
pnpm typecheck
pnpm build
pnpm start
```

`analyze` 应打印哈希核验、H1–H4 的表中数值及 `LLM judge SKIPPED`。`test` 应通过 14 项，`typecheck` 应退出 0，`build` 应静态生成根页面。启动后打开 `http://localhost:3000` 可查看两张表，开发时也可用 `pnpm dev`。

这是只有 40 题的小型合成集，每题三轮。区间受题集构成、样本量和实际重试条件影响，不能外推到真实商品查询、其他模型或生产流量。全对切片的零宽度只反映冻结样本内没有观察到错误。
