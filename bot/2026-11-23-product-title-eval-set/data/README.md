# 冻结数据

`titles.jsonl` 每行是一条德化陶瓷合成商品用例，含一条候选标题。相邻行组成正反例，整组分配到同一 split。数值属性以 mL、cm、件为单位。style 金标表示标题是否可读，合规金标表示此回归用例是否应失败。销售对照的 citation 是虚构的证据范围设定，禁止当作真实宣传素材。

候选标题和标签均为 AI 辅助构造并经 Codex 审阅的回归金标，未做独立真人实验，无用户真人标注。holdout 数据不得用于改风格提示词。本轮跳过风格 judge 标定。

`freeze.json` 记录冻结时间、行数和原始 UTF-8 文件 SHA-256。提交后仅在 JSONL 末尾追加新行，同步记录新版本的哈希、条数和冻结时间；旧行保持字节一致。

合规回归依据已读原文。理念、同品牌自比、商标指代及限定范围事实对应第五条、第六条第一、四、六项，并参考第七条的真实性要求。范围反例用第十三条，自证及举证责任用第十七、十八条。标签供工程回归使用，非法律意见。[《广告绝对化用语执法指南》](https://www.samr.gov.cn/ggjgs/tzgg/art/2023/art_183b5cb48d9e4f0dba67f9f912a913ba.html) · [《广告引证内容执法指南》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/ggjgs/art/2026/art_8962fc1e4eb44a87b93d265af43b6940.html)
